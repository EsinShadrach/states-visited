# My Nigeria 🇳🇬

An interactive map for ticking off the Nigerian states you've visited. Tap a state on the map or pick it from the zone list. It shows your count, progress per geopolitical zone, and can save a shareable PNG.

Single self-contained `index.html`, so no build step. Ticks and your name are stored in your browser (localStorage).

Map data: [svg-maps/nigeria](https://github.com/VictorCazanave/svg-maps) by Victor Cazanave, CC BY 4.0.
